# War 3D — لعبة حرب ثلاثية الأبعاد للأندرويد (Unity)

لعبة إطلاق نار من منظور الشخص الأول: موجات أعداء متزايدة، غطاء من الصناديق، ضربة الرأس بضرر أكبر، وحزم علاج/ذخيرة تسقط من الأعداء.
كل شيء (الساحة، الأعداء، الأصوات) يُبنى بالكود عند التشغيل، فلا توجد ملفات فنية.

## التحكم
- **اللمس:** الإبهام الأيسر = حركة، الإبهام الأيمن = تدوير الكاميرا، الزر الأحمر = إطلاق نار.
- **على الكمبيوتر / داخل المحرر:** WASD للحركة، زر الفأرة الأيمن للتدوير، Space أو الزر الأيسر للإطلاق.

## بناء ملف APK عبر GitHub
1. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات هذا المجلد** (يجب أن يكون `Assets` و`.github` في جذر المستودع).
2. أضف ترخيص Unity (المجاني Personal) كأسرار في المستودع: `Settings → Secrets and variables → Actions`
   - `UNITY_LICENSE` = محتوى ملف الترخيص `.ulf`
   - `UNITY_EMAIL` = بريد حساب Unity
   - `UNITY_PASSWORD` = كلمة مرور الحساب

   طريقة الحصول على `.ulf` موضحة في صفحة GameCI: https://game.ci/docs/github/activation
3. ادخل تبويب **Actions → Build Android APK → Run workflow** (أو ارفع أي تعديل على `main`).
4. بعد انتهاء البناء (حوالي 15–30 دقيقة في أول مرة) نزّل الـ Artifact باسم `war3d-apk` وثبّت ملف `war3d.apk` على جهازك (فعّل التثبيت من مصادر غير معروفة).

## ملاحظات
- الإصدار المستخدم: Unity 2022.3.62f1 (يُقرأ تلقائيًا من `ProjectSettings/ProjectVersion.txt`).
- الـ APK موقّع بمفتاح debug، مناسب للتجربة وليس للنشر على Google Play.
- لتجربة اللعبة محليًا افتح المجلد في Unity Hub.
